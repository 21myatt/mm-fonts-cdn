# Credits

## Original project and code contributors

This CDN builder is based on the
[Myanmar Unicode Fonts](https://github.com/saturngod/myanmar-unicode-fonts)
repository.

- **Htain Lin Shwe / SaturnGod** (`Htain Lin Shwe`, `saturngod`, and
  `Saturngod` in Git history) — original project creator, curator, and primary
  contributor.
- **dependabot[bot]** — automated dependency-update contributions.
- **Aung Myo Kyaw** — curator of the additional non-overlapping font collection
  imported from
  [AungMyoKyaw/Myanmar-Unicode-Fonts](https://github.com/AungMyoKyaw/Myanmar-Unicode-Fonts).
- **Ko Htet Zaw (`khzaw`) and contributors** — curators of
  [awesome-myanmar-unicode](https://github.com/khzaw/awesome-myanmar-unicode),
  used to discover canonical Myanmar font sources.

The three human Git identities above use the same upstream email address and
are credited as one person rather than falsely presented as three contributors.

## Font creators, studios, and collections

The upstream catalog identifies these author or collection groups:

- [Khmer Type](https://github.com/khmertype)
- [Masterpiece](https://sourceforge.net/projects/prahita/files/Myanmar%20Unicode%20Fonts/)
- [Phoenix Digital Art](https://www.facebook.com/PhoenixDigitalArt)
- [One Type](https://www.facebook.com/onetype.fontstudio)
- [A Ka](https://www.facebook.com/profile.php?id=61570100936629)
- [Sai Moon / 21.11 Creative](https://www.facebook.com/21.11creative/)
- Unknown or mixed authors represented by the upstream `Unknown Author` group
- Additional creators represented by the upstream `Other Fonts` group

Each generated `catalog.json` entry preserves the author group and available
source link. Where upstream does not identify an individual designer, this
project does not invent one. If you can document a missing or incorrect credit,
please update the upstream catalog and this file.

## Additional collection source

Additional font files are sourced from Aung Myo Kyaw's repository above. Aung
Myo Kyaw is credited as the immediate collection source, not automatically as
the typeface designer or copyright owner. Embedded font metadata and original
creator rights remain applicable.

Masterpiece Uni Sans was discovered through the awesome-myanmar-unicode list
and obtained from the canonical
[Prahita SourceForge project](https://sourceforge.net/projects/prahita/files/Myanmar%20Unicode%20Fonts/MasterpieceUniSans/).
Prahita's release announcement identifies the font as OFL licensed.
